# Правила интерфейса

Вид «Фарфор и лазурь» в светлой и тёмной схемах; правила действуют на каждом экране фронта. Таблицы
цветов и чисел тест сверяет с `src/theme/tokens.css` в обе стороны, по значению.

## Единый источник

- Цвет, скругление, шрифт и движение — только токены `src/theme/tokens.css`; тема Mantine ссылается
  на них переменными, в месте вызова их не задают. Новый токен и его строка ниже — одной правкой.
- В пропс цвета компонента — только токены (`cssVar(...)`); палитры библиотеки (`color="red"`,
  `color="blue"`) не используются. Статусы — токены `ok`, `warn`, `crit` и их подложки.
- `Card`, `Paper`, `Table` и переключатель сегментами берутся без пропсов цвета: фон, рамки, линии,
  шапку и подписи даёт тема — ступени нейтральных палитр Mantine стоят на токенах.
- У переключателя сегментами пропса `color` нет: он красит выбранную подпись белым
  (`autoContrast`), в светлой схеме — белое на белом.
- Схема — «Светлая», «Тёмная» или «Как в системе», переключателем сегментами; выбор живёт в
  хранилище браузера, до первой отрисовки его ставит скрипт `public/color-scheme.js`.
- Вид соседнего сервиса не повторяется: без стекла, размытия, полупрозрачности и кнопок-пилюль.

## Числа и движение

| Токен                    | Значение                                      | Роль                |
| ------------------------ | --------------------------------------------- | ------------------- |
| `--audit-radius-card`    | `16px`                                        | карточка            |
| `--audit-radius-control` | `10px`                                        | кнопка, поле, метка |
| `--audit-font`           | `'Geologica Variable', system-ui, sans-serif` | текст и заголовки   |
| `--audit-motion-fast`    | `120ms`                                       | отклик под курсором |
| `--audit-motion-base`    | `180ms`                                       | смена состояния     |
| `--audit-motion-slow`    | `260ms`                                       | появление, бегунок  |
| `--audit-motion-ease`    | `cubic-bezier(0.2, 0.8, 0.2, 1)`              | общая кривая        |
| `--audit-workspace`      | `1360px`                                      | рабочая область     |
| `--audit-gutter`         | `28px`                                        | поля по бокам       |

- Рабочая область одна на все экраны: не шире 1360 px вместе с полями по 28 px.
- Кривая одна, кроме пружины у отпускания кнопки. Смена схемы — переходом всей страницы за 260 мс,
  текст и фон вместе. Под курсором ничего не сдвигается: отклик — свет, подложка, кромка.
- «Меньше движения»: длительности — 0, переходов нет; отклик цветом и подложкой — без перехода.

## Текст

- Geologica — со своего адреса, только наборы латиницы и кириллицы. Числа табличные, одной ширины.
- Щит цвета текста: чужая `--text-color` выше по дереву не перекрашивает текст темы.
- Текст страниц клиентов и ответы моделей выводятся только как текст, не как разметка. Держит
  правило eslint З14 (`eslint.config.js`, A391) — ошибка на приёмниках HTML строкой:
  `dangerouslySetInnerHTML` и `srcDoc` в JSX; присваивание `innerHTML`, `outerHTML` и `srcdoc`, в
  том числе через скобки и `Object.assign`; атрибут `srcdoc` через `setAttribute`; вызовы
  `insertAdjacentHTML`, `setHTMLUnsafe` и `createContextualFragment`, в том числе через скобки;
  `document.write` и `writeln`. Разбор `DOMParser` со вставкой узлов не запрещён: это путь для
  очищенного содержимого, а очистку правило не проверяет.

## Таблицы

- Колонки по центру, первая тоже, — из темы; в месте вызова выравнивание не задают (линтер — Ч1.10).
- Ширина колонки — по самому длинному содержимому; строка в ячейке не переносится.
- Строка во всю ширину («пусто», отказ) — с левого края; элемент управления — группой по центру.
- Подсветка строки под курсором — `tint`, без сдвига.
- Неизвестное и отсутствующее — прочерк, а не ноль.
- На телефоне строка — ярусами: имя сверху, значения парами с подписями, действие во всю ширину.

## Браузеры

Chrome и Edge 111+, Firefox 121+, Safari 15.4+. Почему: OKLCH в токенах — с Chrome и Edge 111 и
Firefox 113, без него страница теряет цвета темы; `:has()` в правилах Mantine — с Firefox 121;
`dvh` и `:has()` — с Safari 15.4. Если кнопка получит цвет-переменную в пропсе цвета, Mantine
посчитает оттенки через `color-mix()`, и нижняя граница Safari поднимется до 16.2.

## Проверка экрана

1440 × 900 и 390 × 844 в обеих схемах, таблицы — ещё на 1280; страница не шире окна; 390 — через
рамку. Контраст — тестом над токенами: 29 пар на схему, текст от 4,5 : 1, кромки и кольцо от 3 : 1.
