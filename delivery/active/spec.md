# Spec: своя тема фронта (Ч1.4б)

Полоса та же, что у Ч1.4а: код пишет исполнитель полосы фронта в своей рабочей копии.

Разрез проверяющего 2026-11-19: фронт первой стадии — три поставки по шву «сборка / тема /
клиент». Это Ч1.4б «Тема». Сборка — Ч1.4а, клиент API — Ч1.4в.

Источники:
- слова владельца 2026-11-18 о виде сервиса и его выбор: направление «Фарфор и лазурь» в двух
  темах;
- правила вида проекта (вне репозитория);
- решения проверяющего 2026-11-18 и 2026-11-19.

Номера F сквозные для 4а и 4б: здесь F6, F10–F15, F18–F20, правило сканера — общее A23.

**Шов по объёму** (решение проверяющего 2026-11-19T11:09Z). Срезы идут в порядке 1 → 3 «Шрифт» → 4
«Заглушка, правила и снимки» → 2 «Схема». Если после коммита среза 4 счёт гейта больше 860, срез 2
уходит как есть отдельной малой поставкой «Схема и цвета компонентов» сразу после этой: скриптовая
часть F12, F13, F19 и переключатель схемы на заглушке из F20 — с теми же номерами и подписанными
строками, тестами и строками оракула. Тогда здесь схема следует системе силами библиотеки
(`defaultColorScheme="auto"`), тёмные снимки — флагом браузера. Если 860 и меньше — срез 2 идёт
здесь, и после его коммита счёт больше 1100 — число проверяющему до сдачи.
Примеры 4б владелец подписал 2026-11-19T08:59Z — пачкой с Ч1.4а и Ч1.2в; подпись внёс
проверяющий своим коммитом.

## Problem
У фронта после Ч1.4а — стандартная тема библиотеки. Владелец 2026-11-18: вид не повторяет
соседний сервис «ни в коем случае»; тёмная тема, анимации, плавные переходы и центровка таблиц —
сразу, с первой стадии фронта. Нужны:
- токены «Фарфор и лазурь» в светлой и тёмной схемах — единственный источник цвета,
  скруглений, шрифта и движения;
- контраст, посчитанный тестом над токенами, а не на глаз;
- переключатель «светлая / тёмная / как в системе» без вспышки чужой темы и с плавной сменой;
- шрифт Geologica со своего адреса;
- движение токенами, выключенное при «меньше движения»;
- центровка таблиц умолчанием темы;
- правила интерфейса в репозитории — для всех следующих экранов.

## Users / stakeholders
- **Исполнитель следующих поставок фронта.** Он берёт цвет, скругление, шрифт и движение только
  из темы; правила экрана — из `frontend/UI_RULES.md`.
- **Проверяющий.** Принимает вид по снимкам в обеих темах — 1440 и 390, таблицу ещё на 1280 — и
  по расчёту контраста. Токены сверяет с образцом, который выбрал владелец.
- **Владелец.** Видит выбранное направление на заглушке в обеих темах.

## Сверка с ТЗ

Требование владельца 2026-11-19T11:44Z: «по ходу реализации не отступать от ТЗ».
- **Исполняет.** `docs/TZ.md`, раздел «Что уже зафиксировано в ответах»: строка «Состав» —
  веб-интерфейс, у него своя тема в двух схемах, шрифт со своего адреса и таблицы по центру;
  строка «Доступ» — только команда агентства, отсюда нижняя граница браузеров (сотрудники на
  обновляемых браузерах). Метки статусов в образцах — словами строки «Статусы»: «ОК»,
  «Внимание», «Ошибка».
- **Сверх ТЗ.** Вид «Фарфор и лазурь», тёмная схема, анимации и таблицы по центру — слова владельца
  2026-11-18; строка заглушки — слово владельца 2026-11-19T11:44Z; нижняя граница браузеров —
  решение проверяющего 2026-11-19T11:20Z, владельцу её называет проверяющий.
- **Не делает.** Экраны ролей (строка «Роли») — этап 1.1; выбор схемы человеком и переключатель —
  поставка «Схема и цвета компонентов». Язык интерфейса — русский; три языка ТЗ называет у
  отчётов (строка «Состав»), это этап 1.

## In scope
- **Тема — `src/theme/`:**
  - токены цветов из правил вида проекта в двух схемах, в одном файле — источнике для темы, для
    CSS сборки и для теста контраста;
  - скругления 16 и 10 px;
  - шрифт Geologica, числа табличные;
  - длительности 120 / 180 / 260 мс и одна кривая;
  - `respectReducedMotion` и выключение движения при «меньше движения»;
  - щит цвета текста;
  - рабочая область не шире 1360 px, поля по 28 px;
  - умолчание таблицы: заголовок и ячейки по центру — стилями темы, без пропсов в месте вызова.
- **Переключатель схемы** «светлая / тёмная / как в системе». Выбор переживает перезагрузку. Сбой
  хранилища браузера даёт «как в системе», а не поломку. Смена схемы — плавным переходом
  документа длительностью токена 260 мс там, где переход есть; мгновенно — при «меньше движения»
  и там, где перехода нет.
- **Скрипт схемы — файлом из `public/`, не встроенным.** Он ставит схему до первой отрисовки, без
  вспышки чужой темы. Скрипт и Mantine читают один ключ хранилища.
  - Подключён в `<head>` обычным блокирующим тегом — не `type="module"`, не `defer`, не `async`:
    иначе он выполнится после первой отрисовки.
  - Хеша в имени у файла из `public/` нет: в оракуле сборки Ч1.4а (F5) он — поимённое
    исключение с причиной.
- **Фон и цвет текста обеих схем — в CSS сборки** из того же источника токенов. Переменные
  `cssVariablesResolver` появляются только после запуска React, а до него страница красилась бы
  стандартными цветами библиотеки.
- **Шрифт** — пакет `@fontsource-variable/geologica` 5.3.0 (OFL-1.1): ось толщины, наборы знаков
  латиницы и кириллицы, файлы — со своего адреса. Слово владельца — 2026-11-19T08:28Z, через
  проверяющего. Ставится в этой поставке, не в Ч1.4а.
- **Заглушка** получает переключатель схемы и образцы, чтобы на снимках были все роли цвета:
  - токены: заголовок, текст, приглушённый текст, ссылка, карточка;
  - таблица из трёх строк — по центру, во всю рабочую область до 1360 px;
  - статусы на подложках — успех, внимание, критично.
- **Правила интерфейса в репозитории** (`frontend/UI_RULES.md`) — своими словами, без имён и
  доменов, по правилам вида проекта (вне репозитория); замечания владельца — с датой, без имени.

## Out of scope
- **Поведение кнопок** — блик, свечение, нажатие до 0,96, пружина, волна, рамка до и после
  наведения. Это Ч1.4в, с первой настоящей кнопкой «Спросить ещё раз». Токены движения, которыми
  оно делается, — здесь.
- **Ширина колонки по содержимому и ярусы строки на телефоне** — с первой таблицей данных
  (Ч1.11). Центровка — уже здесь, умолчанием темы. В `frontend/UI_RULES.md` записаны все правила
  таблиц.
- **CSP для встроенного `style` Mantine** — Ч1.5, вместе с заголовками.
- **Инструмент замера по пикселям** — Ч1.11.

## Acceptance (observable)
- [ ] Цвета, скругления, шрифт и движение берутся только из темы. Контраст 29 пар на схему
      держит норму в обеих схемах; расчёт краснеет, если токен испортить. Таблица цветов и чисел
      в `frontend/UI_RULES.md` совпадает с файлом токенов.
- [ ] Схема выбирается из трёх, переживает перезагрузку без вспышки и меняется плавно. Скрипт
      схемы — файлом, блокирующим тегом в `<head>`. Фон и цвет текста обеих схем — в CSS сборки,
      до запуска приложения. «Меньше движения» выключает всё движение.
- [ ] Шрифт — со своего адреса, только наборы латиницы и кириллицы.
- [ ] Таблица по центру — из темы.
- [ ] Заглушка показывает вид: на 1440 × 900 и 390 × 844 в обеих темах, таблица — ещё на 1280;
      страница не шире окна — по снимкам для приёмки.

## Прогоны: семь вопросов

Шагов прогона в поставке нет: вопросы приложены к выбору схемы.

| Вопрос | Ответ |
|---|---|
| 1. Повтор шага | Повторный выбор той же схемы ничего не меняет |
| 2. Сбой и число попыток | Своих повторов нет; сбой хранилища схемы — «как в системе», а не поломка (F12) |
| 3. Потолок | Платных вызовов нет; предел воркеров тестов — из Ч1.4а |
| 4. Обрыв посреди шага | Не относится: шагов нет; перезагрузка посреди смены схемы оставляет сохранённый выбор (F12) |
| 5. Кто ещё меняет те же данные | Схему меняет система — страница следует (F13) |
| 6. Двойное нажатие или запрос | Переключатель идемпотентен; запросов к серверу нет |
| 7. Тревога | Не относится: фронт тревог не шлёт |

## Безопасность

1. **Что появляется.** Шрифт в сборке, скрипт схемы файлом, выбор схемы в хранилище браузера —
   это не данные. Новая зависимость — пакет шрифта.
2. **От кого защищаемся.**
   - Внедрение скрипта: скрипт схемы — файлом, без встроенных скриптов.
   - Запрос к чужому узлу при каждой загрузке страницы, если шрифт брать с сервера шрифтов.
   - Лишнее в зависимости: пакет шрифта ставится с выключенными скриптами установки (Ч1.4а, F17).
3. **Защиты этой поставки.** Каждая краснеет без своей защиты:
   - F12 и F7 (Ч1.4а) — скрипт схемы файлом, блокирующим тегом, встроенных скриптов нет;
     исключение оракула для него — поимённое, с причиной;
   - F6 — шрифт со своего адреса, только нужные наборы знаков.
4. **Что проверит ведущая сессия своими пробами.** Собранные файлы — чужие узлы и встроенные
   скрипты; снимки в обеих темах — 1440 и 390, таблица ещё на 1280; расчёт контраста; токены —
   с образцом, который выбрал владелец.
5. **Открытое.**
   - CSP для встроенного `style` Mantine — Ч1.5.
   - Скрипт схемы без хеша в имени — для Ч1.5: этот файл отдаётся без долгого кеша.
   - Вывод текста страниц клиентов и ответов моделей только как текст — правило в
     `frontend/UI_RULES.md`, исполняется с первым экраном, где такой текст появится.
6. **Опора на опись защит соседа.** Ссылки на строки З и Б — после приёмки описи. Уже
   известно: у соседа скрипт схемы встроенный, CSP пропускает его по хешу; мы делаем файлом.

## Non-functional
- Цвет, скругление, шрифт и движение в месте вызова не задаются: только токены темы.

- Строки до 100 знаков, форма — prettier по шаблону канона.
