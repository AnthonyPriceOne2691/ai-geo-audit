## In scope
- **Модуль `ai_geo_audit/alerts.py`** — слой между `storage` и `logs` (В5): сам зовёт только
  `config`, `logs` и `redis`; его зовут `storage`, `settings` и `api`:
  - `queue_alert(level, title, lines, todo)` — текст: `[ai-geo-audit] <УРОВЕНЬ>: <заголовок>`, вне
    боя после имени — ` · <APP_ENV>`; строки тела; последней — «Что делать: …»; время — UTC с `Z`.
    Уровни — СБОЙ, ВНИМАНИЕ, ВОССТАНОВЛЕНО, ПРОВЕРКА. Простой текст, без разметки;
  - длина — до 4 096 единиц UTF-16: Telegram считает знаки в UTF-16 (второе чтение), а такой счёт
    не меньше счёта кодовых точек (вывод). Заголовок длиннее 200, совет длиннее 500 и строка тела
    длиннее 1 000 единиц обрезаются с «…» до счёта; дальше режутся строки тела с конца, на их месте
    — «…ещё N строк» с формой слова по числу: 1 строка, 2 строки, 5 строк. Последняя строка цела;
  - откуда правило: у аутрича отправитель сервиса режет до 4 096 знаков, `alert.sh` — до 3 500
    байт (3-resume:22–23), список однотипных кончается «и ещё M» (3-resume:25, :78); «…ещё N строк»
    — решение 11:49Z, 4 096 с целой последней строкой — 12:33Z. Дословно аутрич это не повторяет;
  - строки тревоги до постановки проходят вычистку журнала (Б16, Ч1.3б): секрет настроек внутри
    строки становится маской. Правило для авторов — в докстринге: без данных клиента и без имени
    класса исключения (PHASES:69) (В7);
  - постановка — запись JSON только из ASCII: `id` — 32 знака hex из `uuid4`, `ts` — UTC до
    секунды, на `Z`, `text`. Одной транзакцией `MULTI`: запись — в начало
    `ai-geo-audit:alerts:out`, список — не длиннее 1 000; отброшенное с хвоста прибавляется к
    счётчику `ai-geo-audit:alerts:dropped`, его читает а2, и пишется строкой журнала (В2, В3);
  - Redis не ответил за 2 с или ответил ошибкой — строка ERROR «ТРЕВОГА НЕ ПОСТАВЛЕНА» с видом сбоя,
    итог `False`; вызывающий исключения не видит (3-resume:22). Вызов синхронный; асинхронный — с
    первым вызывающим из api, Ч1.14б: функцию без вызывающего тест не держит (L58, В9).
- **Форма записи — договор с а2:** объект JSON ровно с ключами `id`, `ts`, `text`; текст — от 1 до
  4 096 единиц UTF-16; вся запись — одна строка ASCII до 32 КиБ. Почему ASCII — `ch1-14a2-spec.md`.
- **Команда `python -m ai_geo_audit.ops.alerts check`** — модуль вне слоёв (В5): тревога ПРОВЕРКА в
  исходящие, код 0 или 1; до работы — `setup_logging()` и `guard_process()` (L55), все пути текста
  в поток ошибок — через вычистку (L54, L56). Класс отказа, который ловит вход, — в модуле, что не
  бывает `__main__` (L123). Команду `pair` в тот же модуль кладёт а2.
- **Здоровье видит Redis** (решение 13:15Z): `GET /api/health` проверяет базу и Redis разом под
  одной границей `HEALTH_DB_LIMIT_SECONDS` (`api/health.py:30`) — 3 с; Redis — асинхронным
  клиентом, своим соединением без пула, в срок оно обрывается, а не закрывается вежливо (L45).
  Ответили оба — 200 `{"status": "ok"}`; иначе 503 `unavailable` и запись WARNING «здоровье: Redis
  не ответил» с классом исключения и пределом, без адреса и пароля.
- **Redis разработки и CI** (решение 13:15Z):
  - разработка — сервис `redis` в `docker-compose.dev.yml` строкой образа стека «линия@дайджест»
    (`docker-compose.yml:42`, A100), с публичным паролем стенда и своим портом на петле — 6462,
    как 5462 у Postgres (`lsof` 2026-11-25T11:44Z: свободен; 6389 и 6419 заняты соседями, 6379
    займёт любой Redis по умолчанию; повтор сверки — срез 0, decisions). `_DEV_REDIS_URL`
    (`config/domains.py:17`, сейчас — 6379 без пароля) — тем же портом и паролем, последним
    срезом: файл общий с «Учётками-2»;
  - CI — служба `redis` в джобах `tests` и `mutation-shard` рядом с `postgres`: тот же образ по
    дайджесту, пароль — в `command` службы, готовность — `redis-cli -h 127.0.0.1 -e ping` с
    `REDISCLI_AUTH` в окружении службы (L60; без `-e` ответ-ошибка даёт код 0). Тест контракта
    держит образ, пароль, готовность и равенство служб долей и `tests` (A289); порча «служба по
    метке» — красная. Пропуск теста — красное (A106, A107);
  - у каждого процесса pytest своя база Redis из 1–15: он занимает свободную меткой `SET NX` со
    сроком и отпускает в конце; ключи в коде прежние. Redis разработки один на машину, как
    Postgres 5462: его делят все копии и потоки порч, а сессия порчи, снятая по сроку, базу не
    отпускает — её отпускает срок метки (L97). Redis не отвечает или свободной базы нет — одно
    сообщение с причиной и командой подъёма, как у Postgres (A12).
- **Числа:** текст — 4 096 единиц UTF-16, заголовок — 200, совет — 500, строка тела — 1 000 (4 096 —
  решение 12:33Z, остальное — вывод); исходящие — 1 000 тревог (вывод: на сутки молчащего хоста с

## Безопасность
1. **Что появляется.** Клиент Redis в api — пакет `redis`; исходящие в Redis — тексты из кода через
   вычистку; здоровье ходит в Redis по адресу из `REDIS_URL` (секрет настроек); служба Redis в CI и
   Redis разработки — с публичным паролем стенда. Redis стека — без пароля до «Учёток-2». Новых
   входов из сети нет; у api выхода наружу нет.
2. **От кого защищаемся.** Утечка пароля Redis через здоровье — ответ 503 и запись журнала; секрет
   или данные клиента в тексте тревоги; зависший Redis держит вызывающего и здоровье; поток тревог
   переполняет исходящие.
3. **Защиты части.** Каждая краснеет без своей защиты: A243 — 503 без адреса и пароля, предел 3 с у
   замершего Redis; A240 — 2 с, 1 000, ASCII; A241 — маска, простой текст; A242 — `guard_process()`.
4. **Пробы проверяющего:** здоровье при остановленном и замершем Redis; метка-пароль Redis — нет ни
   в ответе, ни в журнале; запись в исходящих — по форме. Полная приёмка поимённо:
   `backend/src/ai_geo_audit/alerts.py`, `backend/src/ai_geo_audit/api/health.py`.
5. **Открытое.** Доставка, пара, крон — а2; лента — Ч1.14б; пароль Redis стека — «Учётки-2».
6. **Опора на опись защит соседа.** Б16 — вычистка журнала, берём и для строк тревоги; Б23 — api без
   выхода наружу — не ослабляем; З88 и З70 — доставка по `ok` и токен вне журнала — в а2.

## Non-functional
- Тесты — на Redis и Postgres стека разработки, в CI — на службах джобы. Пропущенных тестов 0.
- Время в тревогах — UTC с `Z` (b4:377). Строки до 100 знаков, кроме строк таблиц.
