- 2026-11-26T11:50Z · выбрал номер чата тревог `ALERT_TELEGRAM_CHAT_ID` строкой с проверкой старта
  (`-?[0-9]+`, только цифры ASCII; `bab74f1`) вместо поля `int`, как сказано «целое» в In scope
  спеки, потому что у `int` негодное значение роняет импорт конфига ошибкой pydantic с самим
  значением в тексте (L29, L30), а A192 требует причину с именем переменной без значения; `int()`
  к тому же принял бы цифры не ASCII и пробел по краю (тест A192, восемь видов не целого); цена —
  вне боя негодный номер не ловится: проверка старта в `dev` и `test` молчит; в бою старт api
  громко отказывает. Подписанный текст спеки не меняется — пункт ведущая показывает владельцу на
  публикации.
- 2026-11-26T11:50Z · выбрал оставить в зелёном `bab74f1` правки утверждений прежних тестов —
  таблица A8 `CASES` (+2 строки пары бота), набор имён api в A72, маска прогона A172 (5 → 6
  секретов) — вместо переноса их в красный `1244dee`, потому что ветка уже на GitHub (черновой
  запрос №37), а переписывать её историю (`rebase`, `push --force`) нельзя; цена — пары
  красное → зелёное у этих трёх утверждений нет: на `1244dee` они зелёные со старым числом, их
  держит только зелёный коммит. Впредь правки прежних утверждений, что растут с примером, — в
  красный коммит вместе с новыми тестами (замечание третьей проверяющей на `fdfd18c`).
- 2026-11-26T11:50Z · выбрал блок «сервер» `.env.example` строками `# ИМЯ=значение` под
  строками-пометками `## создаёт скрипт`, `## задаёт владелец`, `## пишет выкат` (`0c1ef15`)

  конца: пометка в той же строке сломала бы заглушки паролей и адресов; цена — пометка видна по
  заголовку группы, а не у имени, и порядок имён файла сервера — порядок блока.
- 2026-11-26T11:50Z · выбрал для `put-secret` входящий файл только из каталога входящих
  `/etc/ai-geo-audit/incoming/` вместо любого пути под своими корнями, потому что иначе командой
  можно «внести» сам файл сервера или мастер-ключ; цена — владелец и ведущая кладут файл именно
  туда, памятка 6а-3 это скажет.
- 2026-11-26T11:50Z · выбрал отказ `env-init`, когда мастер-ключ есть, а файла окружения нет,
  вместо нового ключа, потому что ключами сервисов в базе владеет прежний ключ: новый сделал бы
  их нечитаемыми (A220); цена — прерванный первый запуск разбирают руками по памятке.
- 2026-11-26T12:05Z · выбрал оставить в зелёном `0c1ef15` правку утверждения и оснастки — счёт
  отказа «только из каталога входящих» по выводу (`ctx.out`, 2), а не по выводу с журналом
  (`said`, 4), и `/etc` в фикстурах тестов, а не в подставном контексте `make_ctx`, — вместо
  переноса в красный `248b4f1`, потому что `fc5061c` выложен на GitHub, а переписывать историю
  нельзя; обе правки — ошибки теста, найденные кодом: каждая строка хода идёт и в вывод, и в
  журнал, а `/etc` в `make_ctx` ломал прежний тест 6а-1, что сам заводит его; цена — у этого
  утверждения нет пары красное → зелёное. Со среза 4 правки прежних утверждений — только в
  красных коммитах (мелочь 3 приёмки среза 3; красный `aa4d71a` уже несёт `PROD_RULES == 31`).
- 2026-11-26T12:05Z · выбрал считать порчу «`exists` вместо `lexists`» в `Files.exists`
  равнозначной вместо теста на её смерть, потому что `own` отказывает по ссылке на месте пути
  раньше обоих: проба — висячая ссылка на месте файла сервера во временный каталог, `env-init` с
  кодом и с порчей — отказ «… — ссылка: скрипт по ссылкам не ходит» сразу, мастер-ключа нет, по
  ссылке ничего не создано; 24 из 24 тестов файла сервера зелёные с порчей (мелочь 4); цена —
  `lexists` держится как страховка, если `own` когда-нибудь пустит ссылку. Тест висячей ссылки
  — `10f2a43`.
- 2026-11-26T12:05Z · выбрал снимать сборку своих образов в боевом наложении тегом compose
  `build: !reset null` (`b6354a1`) вместо одного `pull_policy: never`, потому что при `build` в
  слитом выводе `up` соберёт недостающий образ на сервере, а A181 говорит «на сервере ничего не
  собирается» и ждёт, что порча «`image-digest` судит и `${VAR:?…}`» даёт три нарушения на
  настоящих файлах — это верно только без `build` (проба compose 5.7.1 2026-11-26T11:55:43Z:
  `!reset null` убирает `build` из вывода `config --no-interpolate`); цена — хук `check-yaml`
  тега не знает: наложение исключено из него и проверяется вторым хуком `check-yaml --unsafe`
  только на синтаксис, смысл — `docker compose config` шага A89 оракула.
- 2026-11-26T12:05Z · выбрал, что образ строкой, `${VAR}` и `${VAR:-…}` у migrate, api и web
  краснеет в двух правилах — `image-from-server` и `image-digest` — вместо одного, потому что
  такой образ и не из файла сервера, и не закреплён дайджестом; `image-digest` молчит только у
  `${VAR:?…}` своих образов (A181, вторая строка); цена — проба на такой образ ждёт два
  нарушения, а не одно, как прочие пробы правил.
