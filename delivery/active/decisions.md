# Decisions — справочник: таблицы, файл и проверка (`ch2-01-thresholds`)

Решения освежения 2026-11-26; решения черновика 20.11 — в спеке и плане, со своими датами.

- 2026-11-26 · выбрал границу «здесь — всё, что не пишет справочник; загрузка, `status`, замок,
  знак при записи и гонки — Ч2.1б вместе с правкой порогов» вместо границы черновика 20.11
  «правка порогов отдельно, остальное здесь», потому что черновик по мере L125 (код × 2, тесты ×
  3) — около 2720 строк при пределе владельца 2500, а Ч2.1б с одной правкой — около 450.
  Предложение исполнителя; решает ведущая.
  Цена: Ч2.1б вырастает до около 1170; запись файла приходит в main одной поставкой позже; тесты
  этой поставки ставят редакции помощником сырых вставок.
- 2026-11-26 · выбрал номера примеров черновика без перенумерации — здесь A300–A308, A310, A312,
  в Ч2.1б A309, A311, A313–A319 — вместо новой нумерации под границу, потому что ведущая знает
  примеры по номерам черновика, а у каждого номера остаётся один дом. Строки «было — станет»
  черновика A311 стали строками A304, `check` из A308 и A312 — вместо `load`.
- 2026-11-26 · выбрал ревизию `0003` и пробные ревизии тестов `0004`, `0005` вместо `0002`
  черновика, потому что `0002` заняла ревизия настроек Ч1.12а (main `69b2a9b`); Ч1.7в в main ещё
  нет — кто сольётся вторым, перенумеровывает.
- 2026-11-26 · выбрал строку в готовом `schema.py` и готовую чистку `committed` вместо их
  заведения, потому что оба пришли в main с Ч1.12а.
- 2026-11-26 · выбрал роль `audit_app` процесса `reference` безусловно вместо условия черновика
  «если „Учётки“ в main», потому что «Учётки-1» в main (`58de814`): таблица ролей процессов и
  проверка роли есть.
- 2026-11-26 · выбрал вход команды по образцу `ops.alerts` Ч1.14а1 — `refusal.invalid_settings`
  вокруг импорта, журналы и крючки процесса до работы, класс отказа вне `__main__`, тест
  подпроцессом — вместо входа черновика без крючков, потому что уроки L54, L55 и L123 пришли
  после черновика: в процессе теста вход зелёный, а под `python -m` отказ выходил трассировкой.
- 2026-11-26 · выбрал строгие числа и коды — `Decimal` из текста JSON, булево на месте числа —
  отказ, сравнение значением, код — `fullmatch` и цифры ASCII — вместо проверки черновика без
  этих случаев, потому что L131 и L132: в Python `True == 1` и `3.25 == 3.250`, `$` пропускает
  перевод строки в конце, `\d` берёт цифры других письменностей.
- 2026-11-26 · выбрал непредвиденный сбой `check` строкой «сбой проверки: <тип> — справочник не
  тронут» без текста исключения вместо трассировки через крючки процесса, потому что текст
  исключения может нести текст заказчика (Р9, L57), а вычистка журнала прячет секреты, а не
  тексты файла.
  Цена: подробностей сбоя в выводе нет — их даёт повтор под отладкой на стенде.
- 2026-11-26 · выбрал проверку файла и манифеста до соединения с базой вместо порядка черновика
  без этого правила, потому что битый файл тогда базы не касается, а отказы файла в бою
  проверяются без живой базы.
- 2026-11-26 · выбрал пометку хеша `# pragma: allowlist nextline secret` строкой выше вместо
  пометки в конце строки, потому что так велят конституция, п. 11, и L61: в Python пометка в
  конце строки съедает предел длины.
