# Decisions

- 2026-11-19 · выбрал единый источник токенов `src/theme/tokens.css` вместо токенов в TS с
  переменными через `cssVariablesResolver` (решение проверяющего 2026-11-19, добавка 9), потому
  что переменные resolver появляются только после запуска React, а до него страница красится
  стандартными цветами библиотеки; цена — разбор CSS в `tokens.ts`, один разборщик у темы и
  тестов.
- 2026-11-19 · выбрал скрипт схемы файлом из `public/` вместо встроенного, как у соседа, потому
  что встроенному CSP нужен хеш, который ломается от любой правки скрипта; цена — у файла нет
  хеша в имени: поимённое исключение оракула сборки, и в Ч1.5 он отдаётся без долгого кеша.
- 2026-11-19 · выбрал шрифт пакетом со своего адреса вместо сервера шрифтов, потому что сервер
  шрифтов — запрос к чужому узлу на каждой загрузке страницы и лишний источник в CSP; цена — один
  пакет по слову владельца 2026-11-19T08:28Z и файлы шрифта в сборке.
- 2026-11-19 · выбрал переменный пакет шрифта вместо статичного с отдельными начертаниями,
  потому что переменный — один файл на набор знаков и любая толщина; цена — у переменного пакета
  может не быть CSS по наборам знаков, тогда свои `@font-face` на файлы пакета.
- 2026-11-19 · выбрал расчёт контраста над токенами вместо замера по пикселям, потому что для
  замера нужен браузер в наборе тестов; цена — расчёт не видит сглаживания тонкого шрифта на
  экране; инструмент замера по пикселям — Ч1.11.
- 2026-11-19 · выбрал сверку таблицы `frontend/UI_RULES.md` с токенами ровно, в обе стороны,
  вместо «в таблице есть эти значения» (решение проверяющего 2026-11-19), потому что тогда токен
  без строки таблицы краснеет; цена — новый токен и его строка в таблице — одной правкой.
- 2026-11-19 · выбрал ключ хранилища, менеджер схемы и переключатель одним модулем
  `src/theme/scheme.tsx` вместо трёх файлов, потому что раскладка по файлу на часть давала 22
  файла из 25 по функции гейта; цена — модуль около 90 строк, у его частей один тест.
- 2026-11-19 · выбрал ссылки темы на токены переменными `var(--audit-…)` и чтение `tokens.css`
  с диска в тестах вместо разбора `tokens.css?raw` в теме, потому что Vitest 5.0.3 отдаёт любой
  `*.css?raw` пустой строкой, и тема в тестах осталась бы без токенов; цена — значений токенов в
  JS нет: цвета Mantine для его расчётов (`theme.colors`, `white`, `black`) остаются
  библиотечными, а его `darken` и `lighten` по OKLCH дали бы чёрный.
- 2026-11-19 · выбрал приставку `--audit-` у токенов вместо коротких имён образца (`--bg`,
  `--ink`), потому что короткое имя может совпасть с переменной расширения браузера или пакета;
  цена — длинные имена в CSS и в теме.
- 2026-11-19 · выбрал свои `@font-face` в `tokens.css` на два файла пакета вместо `wght.css`
  пакета, потому что CSS пакета 5.3.0 объявляет шесть наборов знаков, и все шесть файлов ушли бы
  в сборку; цена — диапазоны знаков переписаны из `wght.css` 5.3.0: при обновлении пакета их
  сверяют с его CSS, оракул ловит только лишний или пропавший набор.
- 2026-11-19 · выбрал цвета токенов в OKLCH без запасных в sRGB вместо двух наборов цветов
  (решение проверяющего 2026-11-19T11:09Z), потому что пользователи — сотрудники заказчика на
  обновляемых браузерах, а второй набор — второй источник правды и ещё один тест на их равенство;
  цена — в браузере старше весны 2023 года страница теряет цвета темы, текст читается на цветах
  браузера, предупреждения старому браузеру нет. Нижняя граница — в `frontend/UI_RULES.md` и
  README; цели сборки не меняются.
- 2026-11-19 · выбрал шов «срез 2 „Схема“ последним и отдельной поставкой при счёте гейта больше
  860 после среза 4» вместо всего объёма здесь (решение проверяющего 2026-11-19T11:09Z), потому
  что срез 1 вышел в 1,7 раза больше оценки, и прогноз поставки — 1085–1230 при пределе 1200;
  цена — если шов сработает, до поставки «Схема» на тёмной системе при загрузке вспышка светлой,
  выбор схемы человеком не хранится, переключателя на заглушке нет.
- 2026-11-19 · выбрал нижнюю границу «Chrome и Edge 111+, Firefox 121+, Safari 15.4+» по тому, что
  сборка использует на деле, вместо границы по одним токенам (решение проверяющего
  2026-11-19T11:20Z), потому что ниже неё часть страницы не работает: `oklch()` в токенах — Chrome
  и Edge 111, Firefox 113, Safari 15; `:has()` в 19 правилах Mantine (выключенные поля, кнопка
  очистки в поле, полосы прокрутки) — Firefox 121, Safari 15.4; `dvh` в 6 правилах — Safari 15.4.
  Сняты по `caniuse-lite` 1.0.30001820 из пакетов фронта, без сети, и поиском по собранным CSS и JS
  2026-11-19; цена — `color-mix()` в коде Mantine эта сборка не вызывает. Если компонент получит
  цвет-переменную в пропсе цвета, граница Safari поднимется до 16.2: в `caniuse-lite` этой строки
  нет, число — по памяти, и сверять его будет поставка, которая так сделает.
