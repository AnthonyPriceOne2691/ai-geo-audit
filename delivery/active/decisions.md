# Decisions

- 2026-11-18 · выбрал перечисления строкой фиксированной длины с проверкой `ck_…` вместо ENUM Postgres, потому что у соседей autogenerate не писал удаление типа, `sa.Enum` хранил имена вместо значений, а новое значение через `ADD VALUE` падало на первой вставке в бою; цена — alembic проверки CHECK не сравнивает, это закрывает своя сверка значений (A16), которая умеет краснеть.
- 2026-11-18 · выбрал помощник перечисления только для `StrEnum` вместо любого `Enum`, потому что у соседа `str()` у перечисления давал имя класса и сравнение со строкой молча не срабатывало; цена — перечисления статусов пишутся только как `StrEnum`.
- 2026-11-18 · выбрал карту типов базы моделей (`int` — `bigint`, `str` — `text`, `datetime` — `timestamptz`) вместо типа у каждой колонки, потому что у соседей переполнилась 32-битная колонка, а длинный хост уронил пачку; цена — узкий тип и плавающая точка ставятся только поимённо, со списком причин, и проверка правил это держит.
- 2026-11-18 · выбрал явный `ondelete` у каждого внешнего ключа и `SET NULL` только с названным тестом пути при обнулённой связи вместо умолчания, потому что у соседа обнуление связи молча рвало путь поиска; цена — строка списка на каждый такой ключ.
- 2026-11-18 · выбрал номера ревизий `0001`, `0002` вместо hex, потому что сканер секретов принимал hex-номера за ключи; цена — две ветки принесут одинаковый номер, и перенумеровывает тот, кто сливает вторым. Повтор и пропуск номера ловит своя проверка цепочки (A17): сам alembic на повторе только предупреждает и говорит о разошедшихся ветках, пропуск не замечает вовсе (проба на стенде 2026-11-18, alembic 1.20.1).
- 2026-11-18 · выбрал тестовую базу через `alembic upgrade head` подпроцессом вместо `create_all` по моделям, потому что сборка по моделям прячет миграции, а команда должна быть той же, что в бою; цена — покрытие файлов ревизий не видно до волны В1, вопрос записан в её черновик.
- 2026-11-18 · выбрал пробы в своей схеме Postgres `probe` вместо фильтра имён в сверке моделей с базой, потому что фильтр мог бы спрятать настоящую таблицу сервиса, а схема разводит их по построению; цена — снос схемы в тестах сносит две схемы, `public` и `probe`.
- 2026-11-18 · выбрал журнал сервиса в `env.py` без `fileConfig` вместо `fileConfig` с `disable_existing_loggers=False`, потому что `fileConfig` по умолчанию выключает уже созданные логгеры, и у соседей тесты журнала после миграции зеленели по построению; цена — секций журнала в `alembic.ini` нет, уровень задают настройки сервиса.
- 2026-11-18 · выбрал помощник alembic в тестах без параметра адреса вместо адреса аргументом, потому что у соседей цикл «вверх, вниз, вверх» однажды прошёл по базе разработки; цена — адрес берётся только из `own_url()`, а проба отказа идёт через подмену `own_name`.
- 2026-11-18 · выбрал отказ помощника перечисления на значении с апострофом вместо разбора удвоенных кавычек в сверке значений, потому что апостроф в значении статуса — опечатка, а не замысел, и отказ при объявлении модели виден раньше любой сверки; цена — такое значение в перечислении не объявить. Нашёл проверяющий на ранней приёмке.
