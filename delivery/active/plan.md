# Plan: своя тема фронта (Ч1.4б)

## Уроки до кода
Прочитано до кода:
- черновик Д2 (рабочий черновик вне репозитория) — раздел «Уроки соседей по теме»;
- правила вида проекта и расчёт контраста ведущей сессии — оба вне репозитория;
- наш `archive/INDEX.md`.

Ниже — суть своими словами и куда урок лёг.

**Вид**
- **Умолчания библиотеки** — главный источник дефектов вида. Поэтому только токены, а контраст
  считается расчётом, а не на глаз (F11, F15).
- **Щит цвета текста.** Необязательная переменная цвета, поставленная расширением браузера,
  перекрашивала текст. Отсюда щит (F10).
- **Скрипт схемы.** У соседа он встроенный, CSP пропускает его по хешу, и хеш сторожит отдельный
  тест. Здесь — файлом, хешей нет (F12).
- **«Меньше движения»** у библиотеки по умолчанию не уважается. Включаем, с тестом (F14).
- **Ширины проверки.** 1440 и 390 в обеих темах, таблица — ещё 1280; снимок 390 — через рамку
  (F20).
- **Замечания владельца к виду** — с датой, в правилах интерфейса. Это источник для следующих
  экранов.

**Наш индекс архива**
- **L5.** Архивация — на handoff в этой же ветке.
- **L11.** Номера примеров сквозные: F продолжаются после Ч1.4а.
- **L13.** Новые файлы — через `git add` по имени.
- **L17.** У каждого теста в описании — свой F.
- **L18.** Порчи проверяющего гоняются до сверки.
- **L21.** Запись lock сверяется с адресом архива по имени и версии из пути: пакет шрифта
  (срез 3) проходит эту сверку вместе со всеми записями.
- **L22.** Пакет шрифта ставится под `min-release-age=14`; после установки — возраст по всем
  парам lock (T1).
- **L23.** Скрипты и поля `package.json` сверяются целиком: шрифт — строкой в
  `approved-packages.json`, без новых полей и скриптов.
- **L24.** Встроенный скрипт для оракула — и `on…=`, и `javascript:`: скрипт схемы — файлом из
  `public/` (срез 2), правило оракула не ослабляется.
- **L25.** Дайджест — с маской `*test*.ts *test*.tsx *test*.mjs`; помощник вне теста с номером —
  с комментарием номера примера.
- **L26.** В `decisions.md` цена — строкой внутри своей записи, не отдельным пунктом.

## Approach

Четыре среза. Каждый — отдельные коммиты; тест сначала красный, потом зелёный.

**1. Тема (F10, F11, F14, F15, F18).**
- **`src/theme/tokens.css`** — единственный источник: 20 цветов в двух схемах, скругления,
  шрифт, движение, рабочая область; значения — из правил вида проекта. В нём же фон и цвет
  текста страницы обеих схем по атрибуту схемы. Файл входит в CSS сборки и действует до запуска
  React, поэтому на первой отрисовке стандартных цветов библиотеки нет (F12).
- **`src/theme/tokens.ts`** — разбор `tokens.css`: тема берёт текст файла импортом `?raw` при
  сборке, тесты — с диска; разборщик один.
- **`src/theme/theme.ts`.** Тема Mantine:
  - `cssVariablesResolver` переводит токены в переменные обеих схем;
  - `respectReducedMotion`;
  - щит `Text`;
  - стили `Table` — заголовок и ячейки по центру.
- **`test/contrast.ts`** — OKLCH → sRGB → формула WCAG, плюс проверка охвата. Это перенос
  расчёта контраста ведущей сессии своими словами. Он нужен только тесту: лежит рядом с тестами,
  в код приложения не входит.
- В оракул сборки — проверка: фон и цвет текста обеих схем стоят в CSS сборки (F12).

**2. Схема (F12, F13, F19).**
- **`public/color-scheme.js`** — читает выбор из хранилища (сбой — «как в системе») и ставит
  атрибут схемы до отрисовки. Подключён в `<head>` обычным блокирующим тегом.
- **В оракул сборки:**
  - скрипт схемы — поимённое исключение из правила «хеш в имени», с причиной;
  - его тег — без `type="module"`, `defer` и `async`, иначе красный.
- **Менеджер схемы для Mantine** — с тем же ключом. Ключ — одна константа, тест сверяет скрипт и
  менеджер.
- **Переключатель** «светлая / тёмная / как в системе». Смена идёт через
  `document.startViewTransition` длительностью токена 260 мс, где переход есть; мгновенно — при
  «меньше движения» и без него.

**3. Шрифт (F6).**
- Пакет `@fontsource-variable/geologica` 5.3.0: импорт только наборов латиницы и кириллицы, оси
  толщины.
- В оракул сборки добавляется проверка наборов знаков.

**4. Заглушка, правила и снимки (F15, F20).**
- На заглушке — переключатель и образцы: токены, таблица из трёх строк по центру во всю рабочую
  область, статусы на подложках — успех, внимание, критично.
- `frontend/UI_RULES.md` — своими словами. Тест сверяет его таблицу цветов и чисел с
  `tokens.css` ровно, в обе стороны (решение проверяющего 2026-11-19): значение разошлось,
  токен без строки таблицы или строка без токена — красный; в таблице обязаны быть 120, 180,
  260 мс и общая кривая. Тогда Ч1.4г добавляет токен кнопок и его строку одной правкой (F15).
- Снимки для приёмки — Chrome без окна:
  - 1440 × 900 и 390 × 844, в обеих темах; для таблицы — ещё снимок шириной 1280;
  - тёмная — через флаг тёмного режима браузера;
  - 390 — через страницу-рамку;
  - снимки — вне git.

## Stack / boundaries
- Шрифт `@fontsource-variable/geologica` 5.3.0 — слово владельца 2026-11-19T08:28Z. Ставится
  здесь, с выключенными скриптами установки (Ч1.4а, F17).

- Тема не знает бэкенда: запросов к серверу нет.

## Rejected alternatives
- **Стандартная тема библиотеки с тремя правками** — отвергнута, потому что владелец 2026-11-18
  потребовал свой вид, не повторяющий соседа, и выбрал «Фарфор и лазурь».
- **Встроенный скрипт схемы** — отвергнут, потому что CSP тогда нужен хеш, который ломается от
  любой правки скрипта. Файл из `public/` CSP пропускает как свой.
- **Шрифт с чужого сервера шрифтов** — отвергнут, потому что это запрос к чужому узлу при каждой
  загрузке страницы и лишний источник в CSP.
- **Статичный пакет шрифта с отдельными начертаниями** — отвергнут, потому что переменный пакет —
  это один файл на набор знаков и любая толщина.
- **Замер контраста по пикселям в этой поставке** — отвергнут, потому что для него нужен браузер
  в наборе тестов. Расчёт над токенами дешевле и краснеет на порче; инструмент по пикселям —
  Ч1.11.
- **Токены только в TS и переменные через `cssVariablesResolver`** — отвергнуты, потому что
  переменные появляются после запуска React, а до него страница красится стандартными цветами
  библиотеки.

## Risks
- **Цвета в OKLCH.** Mantine принимает цвет строкой, но часть его расчётов (оттенки, `rgba`)
  ждёт hex или rgb. Если OKLCH ломает расчёт библиотеки, токены записываются в sRGB, переведённые
  расчётом теста контраста; в код приложения расчёт не входит. Проверить на первом срезе.
- **Переход документа в jsdom не существует.** Тест проверяет путь вызова (с переходом, без него,
  при «меньше движения»), вид смотрит проверяющий.
- **Наборы знаков шрифта.** У переменного пакета может не быть CSS по наборам знаков — тогда свои
  `@font-face` на файлы пакета, только латиница и кириллица.
- **Таблица-образец на 390.** Ярусов строки на телефоне ещё нет (Ч1.11): колонок в образце
  столько, чтобы на 390 страница оставалась не шире окна.

## Rollout / migration
- Фронт ещё нигде не выкатывается: образ и nginx — Ч1.5. Скрипт схемы и шрифт лежат в сборке.

## Test / eval strategy
- Vitest и jsdom, цепочка `npm run check` из Ч1.4а.
- Ручные порчи:
  - токен приглушённого текста светлее;
  - `respectReducedMotion` выключен;
  - сбой хранилища ломает страницу;
  - щит снят;
  - центровка таблицы снята из темы;
  - ключи хранилища у скрипта и менеджера разошлись;
  - переход вызывается и при «меньше движения»;
  - длительность перехода — умолчание браузера;
  - файл шрифта другого набора знаков;
  - скрипт схемы с `type="module"`, `defer` или `async`;
  - фон и цвет текста убраны из CSS сборки;
  - таблица в `frontend/UI_RULES.md` разошлась с токенами.
- Снимки 1440 × 900 и 390 × 844 в обеих темах, таблица — ещё 1280; для приёмки проверяющего,
  вне git.
- Сканер слов и поясов РФ и РБ — по новым файлам и lock (A23).
