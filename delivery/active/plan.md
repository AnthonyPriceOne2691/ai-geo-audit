# Plan: пакет, конфиг с проверкой на старте, логи (Ч1.1)

## Approach
- Перенос продуктового кода из двух соседних проектов, без механики контура:
  классы настроек по доменам и модуль логов — из одного, проверка старта со сбором
  всех недостающих разом — из другого. Перед переносом — поиск слов и поясов РФ и РБ.
- Дописано то, чего не было ни у кого: id запроса и аудита, время в UTC в обоих
  форматах, вычистка секретов из готовой записи, требования по процессам, отказ на
  заглушке из `.env.example`.
- Пять маленьких доменов — одним файлом `config/domains.py`; домен, который вырастет,
  уходит в свой файл.

## Stack / boundaries
- `backend/` — раскладка канона (CQG §6: `LINT_BE_DIR=backend`); пакет
  `backend/src/ai_geo_audit/`, путь пакета для гейтов зададим в В1 переменной
  `LINT_PY_SRC`, без правки скриптов.
- Окружение читается только в `ai_geo_audit.config`; `logs` зависит от `config`.

## Rejected alternatives
- Конфиг соседнего сервиса целиком — отклонён, потому что в его `config/` 22 файла
  под его домены, а нам нужны 5 доменов.
- Отказ по первой найденной проблеме — отклонён, потому что на сервере каждая
  попытка — это выкат: по одной переменной за раз чинить N раз.
- Фильтр секретов по именам полей — отклонён, потому что секрет приезжает и в тексте
  исключения, и в адресе запроса httpx — по имени поля их не поймать.
- Свой разбор окружения вместо pydantic-settings — отклонён, потому что типы и границы
  (`JWT_TTL_HOURS` 1–168, список значений `LOG_FORMAT`) пришлось бы покрывать заново.

## Risks
- Секрет короче 6 знаков не маскируется (иначе маска съест обычные слова). В бою
  секреты — 64 знака hex, проверка старта требует от 32 байт.
- Экземпляры конфига создаются при импорте: тесты создают свои экземпляры после
  подмены окружения, а не правят общие.

## Rollout / migration
- Поведения у работающего сервиса нет: точек входа ещё нет (Ч1.3).

## Test / eval strategy
- pytest: по тесту на каждый пример A1–A6, A8; A7 — сканер, `eval-smoke.md`.
- Тесты проверены порчей кода: ручные мутанты, по одному на правило (`verify-report.md`).
