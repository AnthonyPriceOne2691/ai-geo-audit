## Уроки до кода

**Клиент и отказы** (разбор 19.11)

  хотя сервис 401 не отвечает никогда (F22, F23).

**Кэш запросов** (разбор исходников TanStack Query 19.11; на срезе 0 — заново на версии дня кода)

## Approach

## Stack / boundaries
- Два новых пакета — словом владельца, точными версиями (F17); `@tanstack/react-query` — в сборку,
  `@testing-library/user-event` — в тесты.
- Запросы — только через клиент: `fetch` — только в `src/api/client.ts`.
- Клиент знает об API только договор: пути, форму отказа, признак отказа, тело здоровья, ответы web.
- Слой `src/api/` не знает страниц и темы.

## Rejected alternatives
- **Две поставки, 4в и 4д** — отклонено, потому что слово владельца 2026-11-26 на список ведущей
  сводит их в одну, а мера около 2200 укладывается в предел; шов остаётся страховкой.
- **`redirect: 'error'`** — отклонён: перенаправление стало бы ошибкой сети, неотличимой от обрыва.
- **`AbortSignal.timeout` для предела** — отклонён: его не двигают управляемые таймеры теста.
- **401 без вызова — «входа нет»** — отклонено: сервис не отвечает 401 никогда.
- **«Входа нет» по тексту отказа** — отклонено: текст поменяют, признак — договор.
- **Свой хук запроса без кэша** — отклонён: экраны дальше стоят на библиотеке, повтор и отмену
  пришлось бы писать дважды.
- **Только `retry: false`** — отклонено: запрос уходит снова на возврат во вкладку и на появление
  сети.
- **Сбой проверки связи — ошибкой запроса** — отклонён: при новом запросе библиотека стирает
  прежнюю ошибку, и экран мигает «Спрашиваем сервер…».
- **Ответ прокси Vite по умолчанию (500) или свой 502 без тела** — отклонены: экран в разработке
  говорил бы не то, что в бою; web отвечает образцом `proxy-bad-gateway`.
- **`host: true` ради проверки с телефона** — отклонён: сервер виден всей сети; снимок 390 —
  рамкой на своей машине.

## Risks
- **Мера у шва.** Прогноз после среза 1 близок к точке 1496: тесты клиента — самая тяжёлая часть.
  Выше — режем по шву.
- **Шов и мёртвый код.** Если режем, клиент без экрана до 4д: мёртвый код В1б может назвать его
  мёртвым — решение на срезе 0 по пробе knip, исключение — поимённо с причиной.
- **Порчи на запросе.** Stryker В1б мутирует все правленые файлы фронта: бюджет 300 с — замер на
  срезе 0; не укладывается — вопрос ведущей до кода.
- **Среда тестов.** В jsdom нет `AbortSignal.any` и `PointerEvent`: `AbortSignal`, `fetch` и
  `Response` — из Node.
- **Перенаправление в двух средах:** в браузере `opaqueredirect` без кода, в Node — с кодом; вид
  браузера — подставным ответом, сверка в живом браузере — проба проверяющей.
- **Сервер разработки в тесте:** старт около секунды, закрытие в `finally`; свободный порт между
  выбором и стартом может занять другой процесс — тест красный с номером, а не ложный зелёный.
- **Срок долга.** Срез 4 — не раньше 2026-11-30T21:52Z; поставка раньше этого времени ждёт его или
  долг переходит дальше — решение ведущей.

## Rollout / migration
- Ничего не выкатывается: сервер разработки живёт на своей машине. Путь `/api` тот же, что у web.
- На первом выкате заглушка через web говорит «Сервер отвечает» — шаг через web в `eval-smoke.md`.

## Test / eval strategy
- Vitest и jsdom, не больше двух воркеров; тесты перенаправления и сервера разработки — в среде
  Node. Цепочка `npm run check`, CI — джоба `frontend` В1б; доля порч — от 60 %.
- **Тесты — это примеры F21–F39, F47–F49, F51, F52:** каждый — файлом теста с номером примера в
  имени теста (дайджест). Порчи кода `frontend/src` судит Stryker гейта В1б в CI на каждом запросе;
  ручные порчи ниже — пробы сверх тестов, а не вместо них (находка 5 В1б): то, чего Stryker не
  портит, — конфиг Vite, правила слоёв, файл договора, обвязка тестов.
- **Ручные порчи — клиент:** `Authorization`; без `no-store`; путь `//узел` или без `/api/` доходит
  до сети; `redirect` по умолчанию или `follow`; одна из форм перенаправления мимо; 401 без вызова
  — «входа нет»; «входа нет» по тексту; потерян вид или признак повтора; снята ветка 413, 429,
  502–504 или 5xx; `TypeError` при чтении тела не перехвачен; предел снят или теряется при своём
  сигнале; отмена — обрыв; 200 со страницей или с двумя признаками из трёх — успех; тестовый
  сервер не помнит промах; образец файла без строки в таблице теста.
- **Ручные порчи — кэш и экран:** повторы по умолчанию; `refetchOnWindowFocus: true`;
  `refetchOnReconnect: true`; повтор кнопкой с умолчанием; клиент кэша в разметке; `networkMode`
  по умолчанию у запросов или изменяющих; `retry: 3` у изменяющих; сбой — ошибкой запроса;
  `detail` разметкой; текст вне `role="status"`.
- **Ручные порчи — сервер разработки:** снят `strictPort`; порты соседа; `preview` на 4173; порт
  «0» принят; прокси переписывает путь; недоступный API — 500; `host: true`.
- **Живой прогон** — сервер разработки с настоящим API: заглушка говорит «Сервер отвечает»; API
  остановлен — текст образца `proxy-bad-gateway`. Шаг через web — в `eval-smoke.md`.
- **Снимки блока** (F47) — в обеих схемах, вне git.
- **Сканер A23** — шаблоны правила LOGIC-10 и «пояс машины» по новым и изменённым файлам и lock.
