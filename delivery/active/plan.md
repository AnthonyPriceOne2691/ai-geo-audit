## Stack / boundaries
- **Пакет `redis` — новая боевая зависимость**, словом владельца с подписью плана:
  - версия 8.1.0 — последний выпуск старше 14 суток: PyPI, перечитано 2026-11-25 — выпуск
    2026-07-30T08:50Z, колесо `py3-none-any`, `Requires-Python` от 3.10; 8.2.0 — 2026-11-23,

    сдвигается: правило 14 суток — нижняя граница возраста; сдвиг открыл бы новые версии всех

## Risks
- **`redis-py` 8.1 и redis 7.4 стека** — сверка в срезе 0; расхождение — проверяющей.
- **Redis разработки один на машину** — его делят копии и потоки порч: баз 1–15 может не хватить.
  Нет свободной — одно сообщение, а не ожидание; снятая сессия отпускает базу сроком метки (L97).
- **«Учётки-2» параллельно** — общие файлы последним срезом; с их паролем стека здоровье впервые
  судит пароль в адресе api: расхождение — api unhealthy в стеке, причина — в журнале api (L134).
- **api без `depends_on: redis`** — в первые секунды стека здоровье 503, пока redis не готов;
  окно держит `start_period` api 20 с (Ч1.5а).
- **Порт Redis разработки** может занять сосед — выбор в срезе 0, как 5462 у Postgres.
- **Служба CI с `command`** — проверяется первым прогоном ветки; не стартует — стоп и
  проверяющей.
- **`merge_guard` под окружением корня** (L114) — пакета `redis` там нет до `uv sync --frozen`.
